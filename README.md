# Vstring 🎸

Let the strings tell your story...

**Vstring** is a virtual guitar website made with HTML, CSS, and JavaScript. Explore acoustic and electric guitars, click on their strings to play musical notes, and enjoy a simple interactive guitar experience!

### Demo-Link: [Vstring](YOUR_LIVE_DEMO_LINK)

### The main page:

#### Choose between the acoustic and electric guitar and start playing!

#### Acoustic Guitar

Click on the strings to play different musical notes and explore the acoustic guitar.

#### Electric Guitar

Switch to the electric guitar and play notes with a stronger, distorted sound.

## Built With

- HTML
- CSS
- JavaScript
- Web Audio API
- Google Fonts

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Make sure the HTML, CSS, JavaScript, and `images` files are in their correct locations.
4. Open `index.html` in your browser.
5. Choose a guitar and click on its strings to play!
